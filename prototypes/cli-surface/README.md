# CLI surface prototype — planning archive

Throwaway review artifacts for [CLI surface prototype](https://github.com/talvor/otman/issues/6). No production implementation.

Open `cli-surface-final.html` for the confirmed command contract and final review. `cli-surface-prototype.html` is the first-round in-memory claim/frontier simulation; `cli-surface-round2.html` contains illustrative command/output transcripts. The final contract supersedes abbreviated or conflicting earlier examples.

All recommended choices were explicitly accepted in three live review rounds. The final confirmation authorized resolution. Canonical decision detail lives in the resolution comment on the issue.

Open the HTML files in a browser. Styling uses CDN-hosted DaisyUI/Tailwind; the simulation itself runs locally in memory. Queue controls submit feedback only when hosted through Lavish. This branch archives the review assets and must not be merged as production code.
